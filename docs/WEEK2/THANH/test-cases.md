## Week 2 – Test Case Specification

### 1. Tổng quan

Bộ test gồm 30 test case, bao phủ các nhóm:
- Boot/Hardware
- Timer
- SBI/Console/Shutdown
- HSM/Multi-hart
- Regression/Memory Leak
- Error Handling
